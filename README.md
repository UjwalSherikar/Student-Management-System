# Student Management System

A Java-based Student Management System using Object-Oriented Programming (OOP) and ArrayList.

## Features

- Add Student
- View All Students
- Search Student by ID
- Update Student Marks
- Delete Student
- Calculate Average Marks
- Find Top Student
- Automatic Grade Calculation
- Input Validation

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections
- Scanner

## Concepts Used

- Classes and Objects
- Constructors
- Methods
- Encapsulation
- ArrayList
- Loops and Conditional Statements
- Exception Handling
- Input Validation

## How to Run

1. Install JDK 21 or later.
2. Open the project in Eclipse, IntelliJ IDEA, or VS Code.
3. Run `StudentManagementSystem.java`.
4. Follow the menu displayed in the console.
